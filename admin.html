Al abrir este panel desde GitHub Pages, intentaremos cargar tu catálogo actual. También puedes importar un JSON desde tu computador.

Cómo publicar en GitHub

  1. Selecciona la imagen y completa los campos. La resolución debe ser exactamente 562 × 705 px.
  2. Presiona Agregar al catálogo. Puedes repetirlo para más imágenes.
  3. Descarga el nuevo imagenes.json y súbelo a la raíz de tu repositorio, reemplazando el anterior.
  4. Sube también los archivos de imagen a la carpeta imagenes/ de GitHub, con los nombres indicados en las rutas.
  5. Espera a que GitHub Pages publique los cambios y revisa Pixelia.

Nota: los archivos seleccionados aquí no se suben automáticamente. Conserva una copia del JSON y de tus imágenes originales.
