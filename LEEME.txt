PIXELIA V3 — PANEL VISUAL

1. Mantén los archivos index.html, detalle.html, styles.css, script.js e imagenes.json en tu repositorio.
2. Usa admin.html, admin.css y admin.js en tu computador (no subas admin.html al sitio público).
3. Para usar el panel local con Python, abre CMD en la carpeta y ejecuta: python -m http.server 8000
4. Visita http://localhost:8000/admin.html
5. El panel cargará imagenes.json, permite agregar, editar y eliminar fichas y descargar un JSON actualizado.
6. Sube el JSON descargado a la raíz del repositorio y las imágenes a la carpeta imagenes/.
7. El panel NO sube los archivos por ti ni modifica GitHub automáticamente.
8. Conserva una copia de seguridad de tus imágenes y del JSON antes de reemplazarlo.

El formato de imagen admitido es 562 píxeles de ancho por 705 de alto.
